# URDU MADHYAMIK VIDYALAY UMBARDE MEHBUBNAGAR KOLPE

Editable responsive school website.

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — menu, gallery lightbox, back-to-top
- images/ — school logo and uploaded photographs

## Run locally
Double-click `index.html` or open it in a browser.

## GitHub
Upload all files and folders while preserving the `images` folder.

## Netlify
Import the GitHub repository. Build command: leave empty. Publish directory: `/`.

## Edit
Open `index.html` in VS Code, Notepad++, or another editor and change text as required.
